# 仮説（H）
レッスン外で英語を使う場面を、月1回、3つの選択肢から自分で選ぶ形で提示すると、月1回以上は達成され、1行の物語が残る。自分で選ぶ（自発性）と物語（共有可能性）が、学習を実戦へ接続する。

# 分解
- H3-1: 実戦ログが月1件以上。
- H3-2: 達成した月は、翌月のレッスンの手応え（rating）が上がる。
- H0: 操作チェック — ミッションが提示され、選ばれている（週次報告に3択を載せ、返信で選ばれた回数）。

# 検証設計 ★データ取得前に固定
| 主張 | 指標・データソース | 判定基準 | 判定時期 |
|---|---|---|---|
| H0 | 週次報告の3択への返信 | 10月・11月に各1回以上 | 各月末 |
| H3-1 | real の件数 | 10月・11月に各1件以上 | 2026-11-30 |
| H3-2 | sessions.rating の月平均 | 達成月の翌月が +0.3 以上（参考指標。単独では判定しない） | 2026-11-30 |

# 交絡・バイアス
- 実戦の機会は仕事のイベント（海外候補者・海外パートナー）に左右される。機会が無かった月は「未判定」とし、不成立と数えない。
- 出張・繁忙。

# 外れた場合の解釈候補
- H0 不成立 → 3択が現実の予定と合っていない。カレンダーの実イベントから選択肢を作る。
- H3-1 不成立で H0 成立 → 選んだが動けなかった。難度を下げる（英語で挨拶1文、など）。
