# 仮説（H）
毎月同じ3問（育ち・仕事の外で好きなこと・最近考えていること）に60秒で答える記録は、3ヶ月で語数/分が伸び、詰まりが減る。これはループの外にある独立指標で、「英語が確実に向上している」の検証に使う。

# 分解
- H2-1: 語数/分が +20%（#1 → #4）。
- H2-2: 詰まり回数が −30%。
- H2-3: 固定ルーブリックの Level が +1 以上。
- H0: 操作チェック — 月1回のサンプルが実際に録られている（#1 は 2026-09 中）。

# 検証設計 ★データ取得前に固定
| 主張 | 指標・データソース | 判定基準 | 判定時期 |
|---|---|---|---|
| H0 | samples の件数 | 9月・10月・11月に各1件以上 | 各月末 |
| H2-1 | samples[].wpm | #4（12月上旬）が #1 比 +20% 以上 | 2026-12-07 |
| H2-2 | samples[].stuck_count | #4 が #1 比 −30% 以上 | 2026-12-07 |
| H2-3 | samples[].level | +1 以上 | 2026-12-07 |

# 交絡・バイアス
- 採点のばらつき（同じ発話でも Level が揺れる）。ルーブリックを固定し、システムプロンプトを変えない。変える場合は #1 を再採点して差を記録する。
- お題への慣れ（同じ3問を繰り返す効果）。慣れも「言える自分の話が増えた」の一部と見なすが、12月の判定では G11 の「お題追加」を検討する。
- 文字起こしの精度（ASR）。語数は cleaned_transcript で数える。

# 外れた場合の解釈候補
- H2-1 だけ不成立 → 速さでなく正確さに振っている可能性。詰まりと完全文率を優先して読む。
- 全て不成立で H0 成立 → 練習の中身（ピース）と実戦の接続を疑う。G6 の「場」の提案へ。
