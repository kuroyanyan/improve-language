# 仮説（H）
「予習した」を押したあとに「今日の学習、これで終わりにしますか？」と区切りを置き、毎回変わるねぎらいの一言と今日のワンフレーズ（英語＋日本語）をクラッカーと一緒に出すと、1日の学習が達成感を持って閉じる。
着想: 2026-09-18、黒川さん「最後この予習したまで押せたら、今日の学習をおえますか？みたいなポップが出てきて、毎回変わる褒めの一言、英語と日本語でねぎらいの言葉や使えるワンフレーズがクラッカーの演出と一緒に出てきて達成感が味わえるように」。
根拠は黒川さんの言葉（G3）。器の指標（学習量・連続日数）を増やすことは目的ではない（G0）。

# 変更
- 「予習した」→ ポップアップで「今日の学習、これで終わりにしますか？」（はい／まだ続ける）
- 「はい」→ ねぎらいの一言（英日・12種から前回と違うもの）、今日のワンフレーズ（英日・12種）、宣言したピース、クラッカー
- 結果を `preps[].end`（done / continue）に残す。演出が邪魔になっていないかを見るため
- 責める表現・連続日数・学習量の表示は入れない（G0・G10）

# 分解
- H0: 操作チェック — ポップアップが出ている（`preps[].end` が入っている割合）。
- H1: 邪魔になっていない — 最後まで見た（`end = done`）割合が高い。

| H1 | 同期間の preps のうち end = done の割合 | 70% 以上 | 2026-10-09 |

# 交絡・バイアス
- 目新しさ（最初は珍しいので最後まで見る）。3週の合計で判定する。
- 時間予算（G2）: 1日6分に対して、この演出は2タップ・数秒。超えるようなら削る。
- 同時期に H-20260917_lesson_recording も検証中。予習の回数そのものは両方の影響を受けるため、この仮説では回数を指標にしない。

# 外れた場合の解釈候補
- H1 不成立（done が低い）→ 演出が冗長か、聞き方が邪魔。まず「終わりにしますか？」の一段を削り、1タップにする。それでも低ければ演出ごと削る。
- H0 不成立 → そもそも「予習した」まで届いていない。演出ではなく予習の手前を見る。
