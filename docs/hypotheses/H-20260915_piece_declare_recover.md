# 仮説（H）
「今日これを言う」と予習で宣言したピース（3文＋質問）は、同じ日のフリートークで実際に口から出る。リスク（言えないかも）とリターン（言えた）を同日・同レッスンに置くと、予習文が暗記でなく発話になる。
着想: 2026-09-15、黒川さん「自分について説明することはできるだけ英語で話したい」「自己紹介がとにかくうまくなりたい」。桜井視点のレビュー（宣言→回収＝一番近いリスクとリターン）。

# 分解
- H1-1: 宣言→回収率（見ずに言えた／宣言した）が高い。
- H1-2: 言えるピース（卒業）が積み上がる。
- H1-3: 宣言があるレッスンは、無いレッスンよりフリートーク分数が長い。
- H0: 操作チェック — 予習で宣言が行われている（宣言付き予習の割合）。

# 交絡・バイアス
- 自己申告バイアス（「言えた」の甘さ）。AI FB の piece_use と突き合わせて、乖離が 20pt 超なら自己申告を判定根拠から外す。
- 新規アプリの目新しさ効果。判定は導入後3週の合計で行い、初週だけでは判定しない。
- Rank C 後半（L14〜20）は難度が上がる。

# 外れた場合の解釈候補
- H1-1 不成立で H0 成立 → ピースが長い／難しい。大山スタイル制約を強める（削る方向）。
- H0 不成立 → 予習の時間配分か、ピース作成の摩擦。機能を足さず、作成の手順を短くする。
