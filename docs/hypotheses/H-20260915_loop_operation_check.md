# 仮説（H）
週1の改善ループは、黒川さんに読まれ、返信され、データが届いている。これが成り立たないと、他の仮説の不成立が「施策が弱い」のか「ループが動いていない」のか区別できない。

# 分解
- H0-1: 週次報告への返信率（通知に1行返す）が 50% 以上。
- H0-2: `improve-language-data/latest.json` が毎週更新されている（同期が生きている）。
- H0-3: ループが出した PR は、翌週の実行までに merge か close されている（放置が無い）。

# 検証設計 ★データ取得前に固定
| 主張 | 指標・データソース | 判定基準 | 判定時期 |
|---|---|---|---|
| H0-1 | 週次報告への返信の有無（ループが記録） | 5週のうち3週以上で返信 | 2026-10-19 |
| H0-2 | latest.json の generated_at | 5週のうち4週以上で7日以内に更新 | 2026-10-19 |
| H0-3 | PR の状態 | 放置 PR が0 | 2026-10-19 |

# 交絡・バイアス
- 出張・体調・繁忙（9月末〜10月は採用イベントが多い）。返信率は「関心」でなく「時間」を測っている可能性。

# 外れた場合の解釈候補
- H0-1 不成立 → 報告が長い／読む価値が薄い。報告を3行に切り詰める（機能を足さない）。
- H0-2 不成立 → 同期の摩擦（PAT 期限・オフライン）。手動書き出しに戻すか、同期の失敗表示を目立たせる。
